# tictactoe-cli

A tiny command-line tic-tac-toe game.

## Install

```
npm install -g tictactoe-cli
```

A short native environment check runs on install (prints a friendly message).

## Play

```
tictactoe
```

Cells are numbered 1-9. Two players alternate on the same terminal.

Active.
